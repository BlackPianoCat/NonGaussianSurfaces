# Static plots

Module `nongauss.plots`. Every `plot_*` function returns a matplotlib figure with at most two panels,
and accepts `interactive=True` to return the Plotly version instead (see [Interactive plots](interactive.md)).

::: nongauss.plots
    options:
      members: [plot, KINDS, plot_surfaces, plot_heightmap_mask, plot_distribution, plot_profile_bearing, plot_hhcf_report, plot_spectrum, plot_feasibility, plot_compare, plot_logo, save]
