    API reference

    Generate and measure

    nongauss.surface

    Surface generation (Gaussian scaffold + Johnson marginals via rank mapping) and statistics.

    Credits
    • Method: Yang et al., CMES 103(4), 251-279 (2014).
    • Original MATLAB surface generator: Dr. Vasilis Constantoudis.
    • Python port, extensions and maintenance: Sebastian Korsak (rewritten with Claude).

    SurfaceResult dataclass

    Generated surface and the metadata needed for plots/reports.

    gaussian_surface(N=500, rms=3.0, corlength_x=10, corlength_y=10, alpha=0.9, rng=None)

    Gaussian surface with autocorrelation rms^2 * exp(-r^(2 alpha)), via FFT filtering.

    rank_map(z_spatial, values)

    Give each pixel of z_spatial the value of equal rank from values (keeps spatial layout).

    generate_surface(N=500, rms=3.0, skewness=1.0, kurtosis=3.0, corlength_x=10, corlength_y=10, alpha=0.9, non_Gauss=True, invert=False, clip_percentiles=None, seed=None)

    Generate a (non-)Gaussian self-affine surface and return a SurfaceResult.

    non_Gauss=False -> Gaussian surface only. invert -> flip sign before shifting (also flips skewness). clip_percentiles -> optional (low, high) clip of the noise (biases kurtosis down).

    SAimage_fft_2(N=500, rms=3, skewness=1, kurtosis=3, corlength_x=10, corlength_y=10, alpha=0.9, threshold=None, non_Gauss=True, corr=True, invert=False, seed=None, show=True, clip_percentiles=None, plot_style='rich')

    Backward-compatible wrapper: returns the surface array, optionally plotting it.

    plot_style: 'rich' (summary figures), 'classic' (3D + mask), 'none'. corr is kept for compatibility (the HHCF figure is part of 'rich').

    moments(z)

    (mean, std, skewness, Pearson kurtosis) of an array.

    hhcf_1d(z, axis=1)

    1-D height-height correlation G(r) = sqrt(<(z(x+r)-z(x))^2>) along an axis.

    report_rows(res)

    Rows (name, requested, achieved, % error or None) for a SurfaceResult.

    report_text(res)

    Plain-text report card (requested vs. achieved).

    abbott_curve(z, n=300)

    Bearing-area (Abbott-Firestone) curve: (% of surface above height h, h).

    radial_psd(z)

    Isotropic power spectrum: (wavenumber k in cycles/pixel, radially averaged |FFT|^2).

    pdf_and_qq(res, n=400)

    Fitted Johnson PDF on a grid and Q-Q data vs. the fit, in the surface's shifted frame.

    Returns dict(x, pdf, osm, osr, slope, intercept, r) or None for the two-point 'ST' case.

    log_power_2d(z)

    log10 of the centered 2D power spectrum (axes in cycles/pixel, range -0.5..0.5).

    Plots

    Every plot_* function returns a matplotlib figure (at most two panels), or a Plotly figure with interactive=True.

    nongauss.plots

    Static matplotlib figures: light theme, hillshaded, at most 2 panels each.

    Every plot_* function takes a SurfaceResult (or a pair) and returns a figure. Pass interactive=True to get the Plotly version instead of matplotlib (see interactive.py); use save(fig, path) to write PNG (static) or HTML (interactive).

    Credits: figure design by Sebastian Korsak, with Claude; surface model after Yang et al. (2014).

    KINDS = {'surfaces': plot_surfaces, 'heightmap': plot_heightmap_mask, 'distribution': plot_distribution, 'profile': plot_profile_bearing, 'hhcf': plot_hhcf_report, 'spectrum': plot_spectrum, 'feasibility': plot_feasibility} module-attribute

    plot(res, kind='surfaces', interactive=False, **kw)

    Plot by name: kind in KINDS ('surfaces', 'heightmap', 'distribution', 'profile', 'hhcf', 'spectrum', 'feasibility').

    plot_surfaces(res, cmap=CMAP)

    Gaussian scaffold vs. final surface in 3D (shared height scale).

    plot_heightmap_mask(res, threshold=None, cmap=CMAP)

    Hillshaded heightmap with colorbar, and the binarized mask with its area fraction.

    plot_distribution(res)

    Height histogram with fitted Johnson PDF and mean marker, and Q-Q plot against the fit.

    plot_profile_bearing(res)

    Line profile through the middle of the surface, and the Abbott-Firestone bearing curve.

    plot_hhcf_report(res)

    Height-height correlation along x and y, next to the requested-vs-achieved report.

    plot_spectrum(res)

    2D power spectrum of the surface, and the radial spectrum with the expected high-k power law.

    plot_feasibility(points, k_max=None)

    Johnson (skewness, kurtosis) plane: feasible regions with your request(s) marked.

    points is a SurfaceResult or a list of (skewness, kurtosis[, label]).

    plot_compare(res_a, res_b, labels, cmap=CMAP)

    Two hillshaded heightmaps side by side on a shared color scale.

    plot_logo(res, size=3)

    Small square logo: hillshaded surface, no axes.

    save(fig, path, dpi=140, transparent=False)

    Save a matplotlib figure as an image (closes it; transparent=True for no background) or a Plotly figure as HTML.

    nongauss.interactive

    Interactive Plotly counterparts of every plot in plots.py (same names, white theme).

    You normally call them through plots.plot_xxx(res, interactive=True). Save any figure as standalone HTML with fig.write_html(path).

    Credits: Sebastian Korsak, with Claude; surface model after Yang et al. (2014).

    explorer(param='skewness', values=(-1.5, -1, 0, 1, 1.5), N=96, **fixed)

    Slider over one parameter (skewness, kurtosis, rms or alpha): 3D surface + histogram.

    All surfaces share the seed, so only the chosen parameter changes.

    Johnson distributions

    nongauss.johnson

    Johnson-system fitting (moments -> parameters) and scipy sampling helpers.

    Credits
    • Fitting algorithm: Hill, Hill & Holder (1976), AS 99, via the MATLAB "Johnson Curve Toolbox" by Dave (2021), MATLAB Central File Exchange #46123.
    • Python port (sub_* routines, f_johnson_M): Max Pierini, (c) 2021 EpiData.it.
    • Sampling/dispatch helpers (johnson_dist, sample_johnson): Sebastian Korsak, with Claude.

    f_johnson_M(mu, sd, skew, kurt)

    Use moments to estimate parameters of a Johnson distribution.

    johnson_dist(coef, j_type)

    Frozen scipy distribution for Johnson params (gamma, delta, xi, lam); None for 'ST'.

    With Z ~ N(0,1): SU: xi + lamsinh((Z-gamma)/delta) SB: xi + lam/(1+exp(-(Z-gamma)/delta)) SL: xi + lamexp((Z-gamma)/delta) SN: (Z-gamma)/delta

    sample_johnson(coef, j_type, size, rng=None)

    Draw samples from the fitted Johnson family (always dispatch on j_type).

    johnson_boundaries(skew)

    Kurtosis limits for |skew|: (impossible-below line, lognormal SL line). Above SL -> SU, between -> SB.

    Command line

    nongauss --skew 1 --kurt 4 --alpha 0.7 --out out/ [--interactive]
